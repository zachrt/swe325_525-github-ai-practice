## Workflow Summary
Issues define what needs to be built before writing code. Working on a separate feature branch keeps the main branch stable while changes are tested. Commits act as progress checkpoints along the way. Opening a Pull Request gives a single place to review code diffs, leave feedback, and double-check criteria before merging back into main.
